# 实验6 合金钢、铸铁、有色合金的显微组织观察

来源：习题实验书书内pp.55–61 / PDF63–69。

## 比较矩阵

| 系列 | 观察重点 | 工艺与性能联系 |
|---|---|---|
| W18Cr4V铸态→锻退→淬→回 | 共晶碳化物形态、均匀性、M/基体与未溶碳化物 | 锻造破碎分布、淬火固溶、回火二次硬化分别作用 |
| 奥氏体不锈钢 | 多边形A、孪晶等 | 固溶处理不能解释成普通M淬硬 |
| 灰铁/可锻铁/球铁 | 片状/团絮/球状石墨与F/P基体 | 先分石墨形态，再分基体，不按基体亮暗替代全部分类 |
| Al-Si变质前后 | 共晶硅形貌、初晶与共晶关系 | 变质改善形貌，初生硅与共晶硅不混同 |
| 单相/两相黄铜 | α晶粒、孪晶、第二相分布 | 结合Cu-Zn相图和加工历史 |
| 锡基轴承合金 | 软基体与硬质点 | 跑合嵌藏和支承能力的组织配合 |

## 观察流程

同系列选相同或已知尺度，先观察分布、粗细和连续性，再比较局部细节。记录材料与工艺，用相图和形成机制支持判读。未经浸蚀先观察石墨，浸蚀后观察基体，避免把石墨脱落坑误认夹杂或相。

高速钢白色块状/颗粒状碳化物的形貌可作依据，但仅凭光学图不能认证精确碳化物化学式。奥氏体钢孪晶是一条证据，不应作为唯一充分判据。

## 报告问题

为什么同样都是高硬度材料，冷作模具、热切削工具和轴瓦的组织设计不同？为什么灰铁与球铁基体相同也不能认为性能相同？为什么改用另一种浸蚀剂后相的明暗可能变化？

## 模板

`样品编号 → 材料及真实状态 → 典型/不利视场 → 可见形貌与尺度 → 组织判定依据 → 工艺变化解释 → 对性能的有限推论 → 待进一步确认项目`。

本项目没有真实实验试样和显微测量记录，提供的是学习与报告工具；不要把预期形貌写成已完成实测。
