# 决策速查

| 当看到… | 优先做… | 理由/边界 |
|---|---|---|
| 求初生量、共晶量、总相量 | 分别列式，再交叉核对 | 三者不是同一数量 |
| 所得分数<0或>1 | 检查相区、端点、横轴基准 | 不把错误结果截断到0–1 |
| 冷作后难继续成形 | 分析再结晶中间退火 | 仅去应力未必恢复塑性 |
| 弹簧只需去应力 | 保留冷作强化，研究回复 | 不盲目完全再结晶 |
| 同钢号、同硬度性能不同 | 查组织、截面、取样与历史 | 硬度不是性能全集 |
| 低碳钢要很高表面硬度 | 研究渗碳等增碳路线 | 普通表淬不改变总碳量 |
| 中碳钢表面耐磨、心部韧 | 先满足心部，再表淬低回 | 分工序建立性能 |
| 氮化精密件 | 先调质/去应力、大部精加工 | 层薄，后续磨量受限 |
| 过共析钢切削难 | 查碳化物形态与球化 | 不一律完全退火 |
| 高速钢需热硬性 | 查专门高温淬火及多次回火 | 不套一般碳钢温差规则 |
| 灰铁薄壁发白难切削 | 查局部冷速、成分、孕育 | 与床身残余应力分开 |
| 铝合金淬后需强化 | 先确认可时效体系 | 不是钢的M淬硬 |
| 末端距离J=若干mm | 查径向/介质换算图 | J不是零件层深 |
| 旧书表格给采购牌号 | 按原书解释，再核现行资料 | 不把历史标准当当前保证 |
